# Version 17.0.0 Release Notes

## The app is renamed paystack_frappe

- App name `frappe_paystack` -> `paystack_frappe`; app title and module
  "Frappe Paystack" -> "Paystack Frappe". Doctype names are unchanged:
  Paystack Gateway Setting, Paystack Payment Log, Paystack Refund Log,
  Paystack Customer Authorization, Paystack Settlement and
  Paystack Reconciliation Log keep their data, custom fields and permissions.
- **No `frappe_paystack.*` entry points remain.** The 15.x compatibility layer
  is gone: `paystack_frappe.utils` (the facade and its modules),
  `paystack_frappe.events`, `paystack_frappe.setup`, the deprecated checkout
  endpoints (`validate_payment_link`, `start_hosted_checkout`) and the ERPNext
  shims in `paystack_frappe.api` are dropped. Call the real homes instead:

  | 15.x / 16.1 path | 17.0 path |
  |---|---|
  | `frappe_paystack.api.paystack_webhook` | `paystack_frappe.api.paystack_webhook` |
  | `frappe_paystack.api.start_checkout` | `paystack_frappe.api.start_checkout` |
  | `frappe_paystack.api.get_payment_status` | `paystack_frappe.api.get_payment_status` |
  | `frappe_paystack.api.validate_payment_link` | `paystack_frappe.api.get_payment_status` |
  | `frappe_paystack.api.start_hosted_checkout` | `paystack_frappe.api.start_checkout` |
  | `frappe_paystack.api.create_payment_link` | `paystack_frappe.integrations.erpnext.api.create_payment_link` |
  | `frappe_paystack.api.is_enabled_for_company` | `paystack_frappe.integrations.erpnext.api.is_enabled_for_company` |
  | `frappe_paystack.api.saved_cards` | `paystack_frappe.integrations.erpnext.api.saved_cards` |
  | `frappe_paystack.api.charge_saved_card` | `paystack_frappe.integrations.erpnext.api.charge_saved_card` |
  | `frappe_paystack.utils.get_customer_email` | `paystack_frappe.integrations.erpnext.accounts.get_customer_email` |
  | `frappe_paystack.utils.pos_payment.*` | `paystack_frappe.integrations.erpnext.pos.*` |
  | `frappe_paystack.utils.portal.download_payment_receipt` | `paystack_frappe.integrations.erpnext.portal.download_payment_receipt` |
  | `frappe_paystack.utils.reconciliation_api.*` | `paystack_frappe.core.reconciliation_api.*` |

- The webhook URL changes with the app name. Update the Paystack dashboard to
  `https://your.site/api/method/paystack_frappe.api.paystack_webhook`.

## Upgrading from frappe_paystack (data is kept)

```bash
bench get-app paystack_frappe https://github.com/ugodspecial/Paystack-Frappe
bench --site your.site console
>>> from paystack_frappe.rename_app import adopt_installed_site
>>> adopt_installed_site()
>>> exit()
bench --site your.site migrate
```

`adopt_installed_site` swaps the site's installed-app record and the bench's
apps.txt; the `v17_0.rename_app` patch (pre_model_sync) then renames the
Module Def "Frappe Paystack" to "Paystack Frappe" - every DocType, report,
page, print format, workspace and widget follows - and repoints Patch Log and
Scheduled Job Type rows. Existing payments, refunds, saved cards, settlements,
settings and their secrets stay exactly where they were; only names that name
the app change.
